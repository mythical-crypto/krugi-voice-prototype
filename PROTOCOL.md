# Protocol

Voice worker also emits `{type:"tts_text",sessionId,turnId,text}` immediately before synthesis. This contains the normalized spoken text (numbers expanded) used only by server echo suppression. Displayed assistant text stays unchanged. Short replies are never classified as echo; a client interrupt clears the echo window.

Frontend connects ws://127.0.0.1:3150/ws?session=<id> after POST /api/sessions returns {id}. GET /api/health returns model health. GET /api/catalog returns catalogue.
Client JSON: {type:"start"}; {type:"text",text:string}; {type:"pcm",audio:base64} mono signed PCM16 LE 16000 Hz, chunks ~80ms; {type:"interrupt"}; {type:"stop"}. Max 128KiB frame; max 2000 chars text. Server: {type:"ready"}; {type:"status",status:"listening"|"searching"|"speaking"|"error"}; {type:"transcript",text,final:boolean}; {type:"assistant",text,turnId}; {type:"audio",audio:base64,sampleRate:number,channels:1,turnId:number}; {type:"audio_end",turnId}; {type:"interrupted",turnId}; {type:"quote",quote: Quote|null}; {type:"diagnostic",kind:string,name?:string,args?:object,result?:unknown,durationMs?:number}; {type:"error",message:string}. Browser clears playback immediately on local interrupt; ignores audio from older turnId. Assistant full text emitted before audio chunks. Initial start speaks exact fixed greeting once per session; repeat start on same socket does not repeat. New session repeats greeting.

Voice child JSONL stdin: {type:"asr_start",sessionId}; {type:"pcm",sessionId,audio}; {type:"asr_stop",sessionId}; {type:"tts",sessionId,turnId,text}; {type:"cancel",sessionId,turnId}; {type:"shutdown"}. stdout: {type:"ready",asr:true,tts:true}; {type:"partial"|"final",sessionId,text}; {type:"audio",sessionId,turnId,audio,sampleRate,channels:1}; {type:"tts_end",sessionId,turnId,durationMs,audioSeconds}; {type:"error",sessionId?,turnId?,message}. All diagnostics/logs stderr. ASR and TTS run independently; cancel must suppress queued/stale audio quickly. No torch.

Quote: {programId:string,programName:string,basePrice:number,bonusBalance:number|null,applied:number,total:number,bonusesConfirmed:boolean,sourceIds:string[]}. Catalogue program IDs wheel, handbuilding, date. Shared code import relative to packages/shared/index.ts. Root uses TS strict, ESNext, bundler resolution. Backend is compiled with esbuild to dist/server.cjs (Nest decorators explicit function invocation to avoid metadata requirements). Frontend Vite React 19. Unit/API tests Bun. Runtime server Node.
